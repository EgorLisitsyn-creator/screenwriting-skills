# screenwriting-skills

[English](README.md) · [中文版](README_ZH.md) · [日本語](README_JA.md) · [한국어](README_KO.md) · [Français](README_FR.md)

27 навыков для агентов («skills») по сценарному мастерству, телевизионной драматургии и драматургии вообще, для [Claude Code](https://docs.anthropic.com/en/docs/claude-code/skills) и [OpenAI Codex](https://developers.openai.com/codex/build-skills). Выжимка из 47 книг о ремесле и 23 томов опубликованных сценариев, партитур и пьес (Китай, США, Великобритания, Япония, Корея).

Файлы навыков следуют открытому стандарту [agentskills.io](https://agentskills.io) и общие для обоих агентов: установили один раз — работает в обоих.

**Задавайте вопросы по-русски.** Тексты навыков написаны по-китайски, потому что большинство источников — китайские оригиналы или китайские переводы. Это лишь деталь реализации: спросите по-русски — получите ответ по-русски. Почему дерево исходников только одно, см. [Многоязычность](#многоязычность).

## Установка

### Claude Code

#### Маркетплейс плагинов (рекомендуется)

```
/plugin marketplace add jtydhr88/screenwriting-skills
/plugin install screenwriting@screenwriting-skills
```

Дальше навыки вызываются как `/screenwriting:<навык>`, например `/screenwriting:sw-dialogue`.

#### Личная установка (для всех проектов)

```bash
git clone https://github.com/jtydhr88/screenwriting-skills.git
cp -r screenwriting-skills/plugins/screenwriting/skills/* ~/.claude/skills/
```

#### Для одного проекта

```bash
mkdir -p .claude/skills
cp -r screenwriting-skills/plugins/screenwriting/skills/* .claude/skills/
```

### Codex (CLI / настольное приложение ChatGPT / расширение для IDE)

```bash
codex plugin marketplace add jtydhr88/screenwriting-skills

# Затем в настольном приложении ChatGPT или в Codex CLI:
# Plugins → выбрать «Screenwriting Skills» → Install
```

Для личной установки копируйте в `~/.agents/skills/`, для проекта — в `.agents/skills/`. `/skills` выводит список доступных навыков, `$sw-story-structure` вызывает навык явно.

## Многоязычность

**Одно дерево исходников, любой язык при выполнении.** Навыки написаны один раз, по-китайски, а агент отвечает на том языке, на котором задан вопрос.

Это обдуманное решение, и оно было не первым. Когда-то существовало английское издание — параллельный плагин `screenwriting-en` со всеми 20 переведёнными навыками. Его предложили в [#3](https://github.com/jtydhr88/screenwriting-skills/issues/3), сделали и влили. Потом удалили. Довод, который его похоронил, одинаково применим к любому другому языку: если читатель, не знающий китайского, заслуживает переведённого дерева, то и читатель, не знающий английского, тоже, и следующей просьбой будет японский, потом корейский, потом французский, потом русский. Пять языков — это 230 файлов, которые расходятся каждый сам по себе, и ничто не подскажет, какой из них устарел. Сам перевод обходится дёшево. Настоящая цена в том, что **после первого форка не остаётся принципиальных оснований отказать во втором**.

Поэтому граница проведена на уровне исходников, а остальное делается при выполнении:

- **Язык ответа следует за языком вопроса.** Спросили по-русски — получили по-русски. Никаких флагов и отдельных установок.
- **Терминология привязана к исходному термину.** Словарь этого ремесла изначально английский: *logline*, *act out*, *beat sheet*, *showrunner*, *staff writer*. Китайские слова в книгах-источниках (计程绳, 出幕, 节拍表, 剧目管理人, 试用编剧) — это перевод, причём разные переводчики выбрали по-разному. Таблица терминов в `sw-workflow` возводит каждое понятие к исходному термину, и агент **восстанавливает** слово. Одна и та же таблица служит всем языкам сразу: русскоязычный сценарист тоже говорит *логлайн* и *шоураннер*.
- **Термины без эквивалента сохраняют исходную форму с пояснением.** 戏眼 и 扣子 выводятся как `戏眼 (xìyǎn — центральная приманка серии, формулируемая одной фразой)`.
- **Ваш сценарий остаётся на языке вашего сценария.** Обсуждать китайский сценарий по-русски — нормально: меняется язык разговора, а не текст.

Взамен теряется **проверяемость**: не зная китайского, вы не прочтёте сам файл инструкций, только пересказ агента. Это реальная цена, и это единственное, что действительно давало удалённое английское издание. Постоянной пятикратной нагрузки на сопровождение оно не стоило.

**С README дело обстоит иначе**, и они переводятся: они короткие, стабильные, и именно их новичок видит первыми. Японский, корейский, французский и русский README намеренно ограничиваются установкой, структурой и этим принципом; подробные таблицы навыков и библиография остаются в [английской](README.md) и [китайской](README_ZH.md) версиях — ровно по указанной выше причине.

## Сценические жанры

Кино и телевидение охвачены. Сцена охвачена частично, остальное запланировано, и есть одно правило, что получает отдельный навык: **заставляет ли жанр модель писать нечто с другой структурой, форматом или языковыми правилами?** Если да — отдельный навык; если меняется только тема или стиль — разбор случая внутри существующего навыка.

Китайская музыкальная драма (戏曲) — это **две системы письма**. Для автора важна ось вокальной системы; региональный жанр (剧种) вторичен. В **системе цюйпай** (曲牌体: 元杂剧, 明清传奇, 昆曲) текст вписывается в мелодию с фиксированным шаблоном (число строк, их длина, тоны); 杂剧 состоит из четырёх 折 и одного 楔子, причём весь 折 поёт одна роль; 传奇 делится на 出. В **системе баньцян** (板腔体: 京剧, 豫剧, 越剧, 秦腔, 评剧, 沪剧) текст строится из парных строк по семь или десять иероглифов, варьируемых метром (板式), петь может любая роль, а единица — 场. Различаются и структура, и метод написания арий, поэтому навыков два. Региональные жанры внутри одной системы различаются только таблицей рифм (京剧十三辙 или 豫剧中州韵) и таблицей метров: метод тот же, таблица другая, поэтому это справочные приложения. 粤剧 (смешение обеих систем, к тому же на кантонском) и 川剧 (его 高腔 относится к цюйпай) рассматриваются как пограничные случаи. Сейчас есть четыре навыка (по методу и по библиотеке полных текстов для каждой вокальной системы, выжатые из 25 источников); каждый навык метода открывается таблицей границ медиума со ссылками на источники. Запланировано по порядку: таблица рифм 豫剧 и случай 粤剧, затем разговорный театр 曹禺 и 老舍, и последним — мюзикл. Вертикальные микросериалы и ИИ-генерируемые драмы-комиксы в планы не входят. Новый медиум добавляется как «новый навык, его таблица границ, одна строка в таблице входа `sw-workflow`» без правки общего слоя. Полный текст: [English](README.md#stage-genres) / [中文版](README_ZH.md#舞台门类).

## Четыре слоя

Полнометражный фильм использует слои 1, 3 и 4; сериал — все четыре, потому что сериальный слой **заменяет** «структуру, рассчитанную на фильм», логикой двигателя и сезона.

```
1. Общая драматургия     премиса · структура · персонаж · биография персонажа · диалог · сцена · формат · ведение проекта
2. Слой медиума          сериал · структура серии и сезона · двигатель и библия · writers' room · 30-минутная комедия
                         сцена · китайская музыкальная драма: методы баньцян и цюйпай, у каждого библиотека полных текстов
3. Традиции и индустрия  США · Япония · Корея и Франция · материковый Китай · бизнес
4. Эталонные корпусы     Чехов · Одзу · «Наследники» · разборы сериалов
```

| Слой | Навыки |
|---|---|
| 1 | `sw-workflow` (ведение проекта и story bible) · `sw-story-structure` · `sw-premise-theme` · `sw-character-conflict` · `sw-character-bio` (биографии персонажей и список действующих лиц: форматы сдачи, уровни детализации, рабочие заметки и сдаваемый документ (рабочая версия, если адресата нет), проверка существующего сценария, требования разных адресатов — от японских и корейских конкурсов до заявок на фонды) · `sw-dialogue` · `sw-scene-craft` · `sw-format-adaptation` |
| 2 | Сериал: `sw-series-structure` · `sw-series-engine-bible` · `sw-writers-room` · `sw-sitcom-comedy`<br>Сцена: `sw-chinese-opera-banqiang` · `sw-chinese-opera-qupai` (методы двух вокальных систем) · `sw-chinese-opera-banqiang-cases` · `sw-chinese-opera-qupai-cases` (полные тексты: 锁麟囊, 沙家浜, 白蛇传, 朝阳沟 / 窦娥冤, 救风尘, 牡丹亭, 桃花扇, 长生殿) |
| 3 | `sw-american-case-studies` · `sw-japanese-screenwriting` · `sw-korean-french-screenwriting` · `sw-chinese-series-practice` · `sw-industry-business` |
| 4 | `chekhov-dramaturgy` · `ozu-screenplay-style` · `succession-series-writing` · `sw-series-case-studies` |

У каждого навыка есть основной файл (принципы, чек-листы, порядок работы) и почти у всех — справочный файл (таблицы, подробные разборы, цитаты). Полная таблица того, что содержит каждый навык и из каких книг он взят, — в [английском README](README.md#how-the-skills-are-organised).

Для русскоязычного читателя: `chekhov-dramaturgy` построен на полном собрании пьес Чехова, его письмах и репетиционных записях Станиславского и Немировича-Данченко: четырёхактная структура без центральной кульминации, события за сценой, объявленное событие, которое так и не происходит, конфликт без злодея, цепочки безответной любви, диалог «на полшага мимо», переделка «Лешего» в «Дядю Ваню». А `sw-american-case-studies` разбирает, как устроены сценарии конкретных американских фильмов, от «Человека, который застрелил Либерти Вэланса» до «Вечного сияния чистого разума».
